## 1. 冷启动策略

### 1.1 先选一个城市，不要全国铺开

**选择标准**：

| 维度 | 要求 |
| --- | --- |
| 旅拍热度 | 小红书/抖音有稳定“城市 + 旅拍/穿搭”内容 |
| 供给密度 | 当地有 30+ 家旅拍店/礼服馆/摄影工作室 |
| 酒店密度 | 中高端酒店/民宿集中，方便配送和代收 |
| 场景辨识度 | 有明确风格（海岛/古城/民族/汉服/夜景） |
| 交通 | 机场/高铁便利，游客停留 2–5 天 |
| 季节性 | 全年或大部分时间可经营，避免只做旺季 |

**候选城市对比**：

| 城市 | 核心场景 | 优势 | 风险 |
| --- | --- | --- | --- |
| 三亚 | 海岛、度假、婚纱 | 客单价高、四季可做 | 竞争激烈、夏季淡季 |
| 大理/丽江 | 古城、苍山洱海、民族风 | 内容传播强、供给多 | 同质化、客单价偏低 |
| 厦门 | 文艺、海岛、街拍 | 年轻女性匹配、交通便利 | 台风季、场景集中 |
| 重庆 | 城市夜景、赛博朋克 | 年轻客群、传播强 | 夏季炎热、拍摄时段受限 |
| 西安 | 汉服、唐装、古城 | 服饰租赁天然需求 | 冬季淡季、供给竞争 |
| 长沙 | 街拍、夜生活 | 年轻、短途周末游 | 旅拍属性弱于海岛/古城 |

**建议**：先选 **三亚或大理** 做深。三亚客单价高、酒店配送场景强；大理内容传播强、供给便宜。若你所在城市有资源，优先本地起步，降低 BD 和履约成本。

### 1.2 供给先行：先签商家，再买流量

**签约顺序**：

1. **头部 3–5 家旅拍店/礼服馆**：有客片、有库存、愿意配合平台规则；给首页推荐位/首单补贴。
2. **腰部 10–20 家**：补充风格和价格带，形成“同日多店可租”的供给密度。
3. **独立摄影师/化妆师 10–20 人**：补充套餐和个性化服务。
4. **酒店/民宿 3–5 家**：前台代收、住客权益、二维码曝光。

**签约标准**：

- 营业执照/法人/场地照片；
- 至少 20 套可租实物件，尺码齐全；
- 10 套以上真实客片 + 3 条视频；
- 接受平台价控、押金规则、48h 发货、24h 质检；
- 接受 T+7 结算和售后冻结；
- 缴纳保证金/签署合作协议（可选）。

**首月目标**：

- 签约 15–30 家商家；
- 上线 300–500 个可租实物件；
- 覆盖 5–8 种风格、3 个价格带；
- 每家至少 3 个套餐/组合。

### 1.3 需求获取：内容 + 酒店 + 私域

| 渠道 | 动作 | 目标 |
| --- | --- | --- |
| 小红书 | 目的地穿搭/客片/避坑笔记，挂小程序 | 每月 30–50 篇，积累搜索词 |
| 抖音 | 15–30 秒换装/客片/酒店开箱 | 每月 20–30 条，测试爆款 |
| 酒店/民宿 | 前台二维码、房间卡片、住客群 | 3–5 家，覆盖 500–1,000 间夜/月 |
| 本地商家 | 商家私域/朋友圈/门店海报 | 每家带来 5–20 单/月 |
| 闺蜜/女性社群 | 旅行群、校园大使、KOC 置换 | 20–50 位种子用户 |
| 微信搜一搜 | 目的地关键词布局 | 长期免费流量 |

**内容选题**：

- “来三亚穿什么？5 套海边穿搭不踩雷”
- “大理古城旅拍，租衣 vs 买衣差多少钱”
- “旅拍店不会告诉你的 6 个隐形消费”
- “闺蜜旅拍一天行程：租衣—妆造—拍摄—归还”
- “微胖/小个子/黄黑皮，怎么选旅拍裙”

### 1.4 种子内容与 KOC

- 签约 20–50 位本地 KOC/素人，提供免费租衣或折扣拍摄；
- 交换真实客片 + 1 篇笔记/视频 + 授权平台使用；
- 每城准备 100–200 篇种子内容，覆盖“穿什么/去哪拍/怎么约/多少钱/怎么还”；
- 商家入驻强制上传真实客片，禁止盗图；
- 用“真实客片”而不是“影楼样片”建立信任。

### 1.5 酒店渠道

酒店是租衣履约的关键节点：

- 前台代收/保管，离店代寄；
- 房间放置“旅拍衣橱”卡片/二维码；
- 住客专属折扣/免配送费；
- 酒店礼宾可协助预约摄影/化妆；
- 按订单给酒店返佣或联合营销。

**优先谈**：中高端度假酒店、设计民宿、女性客群强的精品酒店。

## 2. 商家运营

### 2.1 商家分层

| 层级 | 标准 | 权益 | 管理 |
| --- | --- | --- | --- |
| S | 月订单 50+，评分 4.8+，履约 98%+ | 首页推荐、独家款、低抽佣 | 联合运营 |
| A | 月订单 20–50，评分 4.6+ | 搜索加权、活动位 | 定期复盘 |
| B | 月订单 5–20，评分 4.3+ | 基础曝光 | 培训/优化 |
| C | 评分 < 4.3 或履约 < 90% | 限流 | 整改/淘汰 |

### 2.2 商家培训

- 接单时效、发货标准、封签/拍照；
- 清洗消毒流程、面料注意事项；
- 尺码测量、成色分级、损赔标准；
- 客服话术、改期/退款/纠纷处理；
- 平台规则、结算/发票。

### 2.3 履约考核

| 指标 | 目标 | 未达标处理 |
| --- | --- | --- |
| 接单率 | ≥ 95% | 警告/限流 |
| 48h 发货率 | ≥ 98% | 赔付/降权 |
| 准时送达率 | ≥ 98% | 赔付/降权 |
| 归还质检时效 | ≤ 24h | 警告 |
| 差评率 | ≤ 3% | 整改 |
| 赔付率 | ≤ 2% | 复盘/保险 |
| 库存准确率 | ≥ 99% | 下架/整改 |

### 2.4 淘汰机制

- 连续 2 个月 C 级 → 限流；
- 连续 3 个月 C 级或重大投诉 → 下线；
- 虚假库存/货不对板/私下加价 → 立即下线 + 保证金扣除；
- 盗图/虚假客片 → 下架内容 + 处罚。

## 3. 用户运营

### 3.1 行前

- 目的地天气/穿搭提醒；
- 尺码助手/身材档案；
- 行程清单（租衣/摄影/化妆/酒店）；
- 优惠券/套餐推荐；
- 行前 3 天确认配送和拍摄。

### 3.2 行中

- 签收提醒/封签检查；
- 拍摄行程卡（时间/地点/联系人）；
- 续租/换码/加购；
- 客服快速响应；
- 归还提醒。

### 3.3 行后

- 押金退还进度；
- 评价/晒图奖励（优惠券/积分）；
- 同款推荐/下一站推荐；
- 会员/复购券；
- 邀请闺蜜返利。

### 3.4 复购与会员

- 低频业务，复购靠“下一次旅行”；
- 会员权益：免押额度、租金折扣、优先档期、专属客服、生日礼；
- 不建议早期做大额储值/预付卡，合规和信任成本高；
- 用“旅行日历”提醒用户下一次出行。

## 4. 单位经济模型

### 4.1 核心假设

| 参数 | 假设值 | 说明 |
| --- | --- | --- |
| 租衣客单价 | 129 元/3 天 | 中低价位，含 1 套主衣 + 1 件配饰 |
| 租衣平台抽佣 | 25% | 可随品类/商家调整 |
| 摄影客单价 | 899 元 | 2 小时跟拍 + 9 张精修 |
| 摄影平台抽佣 | 15% | 含派单/客服/担保 |
| 化妆客单价 | 299 元 | 到店妆造 |
| 化妆平台抽佣 | 20% | — |
| 摄影加购率 | 租衣订单的 30% | 目标值，需验证 |
| 化妆加购率 | 租衣订单的 15% | 目标值，需验证 |
| 支付通道费 | 0.6% | 微信/支付宝 |
| 平台单均客服/运维 | 8 元 | 按订单分摊 |
| 获客成本 CAC | 80–120 元 | 内容+投放+渠道 |
| 复购率（12 个月） | 20%–30% | 旅行低频 |

### 4.2 单租衣订单

| 项目 | 金额（元） |
| --- | --- |
| GMV | 129.00 |
| 平台抽佣 25% | 32.25 |
| 支付通道费 | 0.77 |
| 客服/运维 | 8.00 |
| **平台贡献毛利** | **23.48** |
| 商家成本（清洗/包装/折旧/配送） | 约 60 |

### 4.3 单摄影订单

| 项目 | 金额（元） |
| --- | --- |
| GMV | 899.00 |
| 平台抽佣 15% | 134.85 |
| 支付通道费 | 5.39 |
| 客服/运维 | 8.00 |
| **平台贡献毛利** | **121.46** |

### 4.4 组合订单（租衣 + 摄影 + 化妆）

| 项目 | 金额（元） |
| --- | --- |
| 租衣 | 129 |
| 摄影 | 899 |
| 化妆 | 299 |
| **GMV** | **1,327** |
| 平台收入 | 32.25 + 134.85 + 59.80 = **226.90** |
| 支付通道费 | 7.96 |
| 客服/运维 | 24.00（3 单） |
| **贡献毛利** | **194.94** |
| 获客成本 | 80–120 |
| **首单贡献** | **约 75–115** |

> 结论：**单卖租衣很难覆盖获客成本；必须把摄影/化妆/套餐的交叉销售做起来。** 租衣是入口，摄影/化妆是利润。

### 4.5 盈亏平衡

简化公式：

```text
月盈亏平衡订单数 = 月固定成本 ÷ 单均贡献毛利
```

| 月固定成本 | 单均贡献 50 元 | 80 元 | 120 元 | 160 元 |
| --- | --- | --- | --- | --- |
| 5 万 | 1,000 单 | 625 单 | 417 单 | 313 单 |
| 8 万 | 1,600 单 | 1,000 单 | 667 单 | 500 单 |
| 12 万 | 2,400 单 | 1,500 单 | 1,000 单 | 750 单 |
| 15 万 | 3,000 单 | 1,875 单 | 1,250 单 | 938 单 |

**判断**：

- 如果团队 5–6 人、月固定成本 8–12 万，单城月订单需 **1,000–2,000 单**才能打平；
- 单城首年做到 1,000 单/月有挑战，所以**首年不要以盈利为目标**，以验证供给、履约、复购和套餐转化为主；
- 降低固定成本（创始人兼运营/客服、外包开发、共享办公）能显著缩短打平周期；
- 提高客单价（摄影/化妆/套餐/会员）比单纯冲租衣单量更有效。

## 6. 预算建议

### 6.1 首年预算（不含创始团队工资）

| 项目 | 金额（万元） | 说明 |
| --- | --- | --- |

| App（二期） | 20–40 | Flutter，可后置 |
| 供给/样品/拍摄 | 3–10 | 自营试点/商家样衣/客片 |
| 市场/内容 | 15–40 | 1–2 城，KOC/投放/酒店 |
| 运营/客服/物流补贴 | 10–20 | 首年 |
| 办公/差旅/杂项 | 5–10 | — |
| **合计** | **约 100–215 万** | 视自研/外包/城市而定 |

### 6.2 精益启动方案（推荐）

如果预算有限，先做“最小验证”：

1. 不开发 App，只做小程序 + 商家 H5 + 后台；
2. 摄影/化妆先做“展示 + 留资 + 定金 + 人工派单”，不建成片交付系统；
3. 社区先不做，用小红书/微信群承接内容；
4. 先签 10–15 家商家、200–300 件衣服，手工 Excel 管库存也能跑前 50 单；
5. 用 3 个月验证“租衣→摄影”加购率和履约，再决定是否加大研发。

**精益预算**：约 **30–60 万**（含外包开发、首批内容、市场）。

## 7. KPI 看板

### 7.1 北极星指标

**月度“租衣 + 摄影”组合订单数**（或月度贡献毛利）。不要只看 GMV，租赁有押金和退款，GMV 会虚高。

### 7.2 供给

- 签约商家数、在线实物件数、风格覆盖数；
- 库存周转率、档期利用率、清洗周转天数；
- 接单率、48h 发货率、准时送达率、差评率、赔付率。

### 7.3 需求

- UV、搜索使用率、商详转化率、下单转化率；
- 客单价、加购率（摄影/化妆）、复购率；
- CAC、LTV、LTV/CAC；
- 内容种草到下单转化率。

### 7.4 履约

- 准时送达率 ≥ 98%；
- 归还准时率 ≥ 95%；
- 质检 24h 完成率 ≥ 95%；
- 押金 3 个工作日退还率 ≥ 98%；
- 纠纷率 ≤ 2%，48h 解决率 ≥ 90%。

### 7.5 财务

- 平台收入、take rate、贡献毛利；
- 押金坏账率、损耗率、物流成本占比；
- 单城盈亏平衡时间。

## 9. 风险与应对

| 风险 | 早期信号 | 应对 |
| --- | --- | --- |
| 供给不足 | 用户搜不到衣服/档期 | 先签头部商家，允许预售/调拨 |
| 供给质量差 | 差评/退款/赔付上升 | 分级、培训、抽检、淘汰 |
| 尺码不合 | 退货率 > 15% | 尺码表/模特数据/免费换码 |
| 卫生投诉 | 用户晒图/差评 | 一客一洗、封签、清洗记录 |
| 履约超时 | 发货/归还延迟 | 48h 发货考核、同城专人、赔付 |
| 押金纠纷 | 退款慢/扣款争议 | 存管、24h 质检、证据、仲裁 |
| 获客成本高 | CAC > 150 | 内容/酒店/私域/复购 |
| 季节性 | 淡季订单下滑 | 多城市/多场景/本地客群 |
| 商家飞单 | 站外交易 | 平台担保、评价、违约金、用户教育 |
| 社区内容风险 | 盗图/虚假/导流 | 机审+人审、举报、黑名单 |
| 合规 | 押金/旅游/隐私 | 法务审核、存管、资质合作 |

---

## 10. 需要验证的关键假设

上线前/首月必须回答：

1. 用户愿意为“租”而不是“买”付多少钱？价格敏感度如何？
2. 租衣订单中，多少人会加购摄影/化妆？目标 30%/15% 是否成立？
3. 商家愿意接受 20%–25% 抽佣和 48h 发货吗？
4. 同城配送/酒店代收/快递归还，哪种履约成本最低、体验最好？
5. 尺码不合/损坏/丢失的真实比例是多少？
6. 获客成本能否控制在 80–120 元？
7. 12 个月复购率能否达到 20%–30%？
8. 单城月订单能否在 6–9 个月内达到 300–600 单？
9. 旺季/淡季的订单波动有多大？库存如何调度？
10. 用户最在意的是“便宜”“好看”还是“省心/不被坑”？

> 建议用 50–100 单真实履约 + 20 个用户深访 + 10 个商家复盘来验证，再决定是否开第二城/做 App/自建供应链。

## 11. 结论

1. **需求真实**：女生旅行“买一次就闲置”的痛点是明确的，租衣 + 旅拍是自然组合。
2. **模式可行但要选对切入点**：租衣毛利薄，必须靠摄影/化妆/套餐提升客单和利润。
3. **首期必须轻**：小程序 + 单城 + 平台轻资产 + 手工履约验证，避免一上来重研发/重库存。
4. **成败在履约**：供给质量、尺码、卫生、归还、押金，任何一项做不好都会毁口碑。
5. **先验证再扩张**：100 单真实履约、30% 摄影加购、押金 3 天退还、差评率 < 3%，再谈第二城和 App。
