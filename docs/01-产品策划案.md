## 0. 一页摘要

**一句话**：为去外地旅行、想拍好看照片的女生，提供“目的地服饰租赁 + 妆造 + 摄影师预约 + 酒店送达/取回”的一站式服务。

**核心洞察**：女生旅行前会专门买“拍照战衣”，穿一次就闲置；到了当地又不知道穿什么、去哪拍、找谁拍。现有旅拍店质量参差、价格不透明，服装、妆造、摄影分散，沟通成本高。

**解决方案**：

- 按目的地/场景/天气推荐穿搭，线上选款、选尺码、选租期；
- 衣服消毒后送到酒店，离店时上门/酒店前台/快递取回；
- 同平台预约当地摄影师、化妆师，行前可沟通，平台担保交易；
- 真实客片社区，先看效果再下单，帖子可挂同款；
- 平台负责商家审核、履约考核、押金存管和售后仲裁。

**商业模式**：前期轻资产平台，签约当地旅拍店/礼服馆/摄影师/化妆师，按订单抽佣；后期做自营爆款、自有品牌和供应链。

**MVP**：微信小程序（租衣 + 摄影预约 + 城市攻略 + 订单/押金/物流）+ 商家工作台 + 运营后台。**先做 1 个城市**，跑通 100 单真实履约，再复制。

## 1. 项目背景与机会

### 1.1 用户痛点

| 痛点 | 具体表现 | 现有解决方式的不足 |
| --- | --- | --- |
| 一次性消费浪费 | 为旅行买 2–5 套衣服，穿一次闲置，占衣柜占行李箱 | 买衣服成本高；日常租衣平台不覆盖目的地场景 |
| 不会搭、不知道穿什么 | 目的地天气、景点风格、出片颜色不匹配 | 小红书内容分散，无法直接转化为“能穿到”的衣服 |
| 旅拍店质量参差 | 客片与实物不符、临时加价、隐形消费、妆造敷衍 | 线下门店信息不透明，缺少平台担保和评价 |
| 服务分散 | 衣服、妆造、摄影师、酒店分别找，反复沟通 | 没有一站式打包，行程衔接容易出错 |
| 归还和押金麻烦 | 异地归还难、押金退得慢、损坏责任说不清 | 传统租赁流程不标准，纠纷多 |
| 行李负担 | 为了拍照带很多衣服、鞋子、配饰 | 快递寄送成本高、时效不稳定 |

### 1.2 市场机会

- **旅拍从“婚纱刚需”扩展到“个人打卡”**：闺蜜游、情侣游、独自旅行、母女游都在为“出片”付费。
- **女性旅行决策权高**： destination look（目的地穿搭）本身是内容消费，天然适合社区种草。
- **供给碎片化**：每个旅游城市都有大量礼服馆、旅拍工作室、独立摄影师、化妆师，缺线上化和标准化。
- **轻资产可复制**：平台不持有库存，先签商家；单城跑通后可快速复制到下一个目的地。

### 1.3 为什么是现在

- 微信小程序生态成熟，支付、定位、分享、IM、物流查询都有现成能力；
- 年轻用户已经习惯“先看内容再消费”，社区与交易可以闭环；
- 旅拍商家经历竞争后，有线上获客和闲置库存变现的需求；
- 信用免押、电子合同、分账、保险等基础设施可降低租赁门槛。

> 注意：这不是一个“纯流量平台”。租衣是重履约生意，供给质量、库存准确率、卫生和归还体验决定生死。前期必须用重运营换口碑。

## 2. 产品定位

### 2.1 定位 statement

> 给旅行中的女生，一个“到目的地就能穿、能拍、能还”的移动衣橱和旅拍管家。

### 2.2 价值主张

**对用户（C 端）**

- 少买一次性衣服，少带行李，花更少的钱穿到更适合当地的服饰；
- 不用做攻略，按目的地/场景直接看搭配和客片；
- 衣服、妆造、摄影一站预约，行程不打架；
- 平台担保、明码标价、押金可退、售后有仲裁。

**对商家（B 端）**

- 闲置礼服/民族服饰/特色服装获得额外周转收入；
- 获得精准的游客订单，降低获客成本；
- 平台提供档期、订单、物流、结算、评价工具；
- 通过客片和社区内容持续曝光。

**对平台**

- 用租衣作为差异化入口，用摄影/化妆/套餐提升客单价；
- 沉淀目的地供给、真实客片和用户身材/偏好数据；
- 后期向自营供应链、自有品牌、会员和广告延伸。

### 2.3 品牌与命名

当前项目**不设品牌名**，统一用 **「未命名项目」** 作为文档、原型和开发阶段的占位名称。

后续如果确实需要品牌化，再单独做命名、商标检索和视觉升级；现阶段先把产品和履约跑通，不把时间花在名字上。

视觉暂定关键词：**干净、靠谱、好看、不踩坑、女生友好**。避开“婚庆影楼风”，走杂志感/旅行手账感，主色可用奶油白 + 珊瑚橘/海盐蓝，后续可随品牌调整。

### 2.4 产品边界：前期不做什么

- **不做全品类日常租衣**：聚焦“旅行拍照”场景，不做通勤/礼服长租。
- **不做自建摄影团队**：前期签约当地商家和自由职业者，平台做品控。
- **不做完整旅游交易**：不卖机票/酒店/跟团游，避免旅行社资质和复杂履约；酒店只做推荐和配送地址。
- **不做重社区**：MVP 只做“目的地攻略 + 真实客片”，发帖和关注放二期。
- **不做全国同时开城**：一城跑通再复制，否则供给和履约会被稀释。

## 3. 目标用户与场景

### 3.1 用户画像

**Persona A：出片型闺蜜游客（核心）**

- 22–30 岁，一二线城市白领/自由职业，年旅行 2–4 次；
- 每次旅行预算 2,000–8,000 元，愿意为“好看的照片”多花 300–1,500 元；
- 习惯小红书/抖音做攻略，重视客片真实感、卫生、尺码；
- 痛点：衣服买一次浪费、行李重、不会搭、怕被旅拍店坑。

**Persona B：情侣/纪念日游客**

- 24–35 岁，愿意为纪念日、生日、求婚拍一套；
- 客单价更高，偏好套餐（服装 + 妆造 + 摄影 + 精修）；
- 决策周期长，需要客服和样片沟通。

**Persona C：民族文化/汉服爱好者**

- 18–30 岁，明确想拍汉服、苗服、藏服、簪花等；
- 对形制、妆造、拍摄地要求高，复购和内容传播强；
- 适合西安、大理、丽江、泉州等城市。

**Persona D：母女/亲子游客（二期）**

- 35–45 岁，寒暑假出行，需要亲子装/母女装；
- 更看重安全、卫生、尺码齐全和拍摄耐心。

### 3.2 用户旅程（行前—行中—行后）

| 阶段 | 用户行为 | 产品承接 | 关键指标 |
| --- | --- | --- | --- |
| 种草 | 刷小红书/抖音/朋友分享 | 小程序内容页、目的地攻略、客片 | 点击率、收藏率 |
| 行前 7–30 天 | 查天气、定酒店、看穿搭 | 目的地页、天气、风格推荐、行程清单 | 加购率、收藏 |
| 行前 3–7 天 | 选衣、选尺码、约摄影 | 商品详情、尺码助手、档期日历、套餐 | 下单转化率 |
| 行前 1–3 天 | 确认配送、沟通拍摄 | 订单跟踪、IM、行前提醒 | 履约准时率 |
| 行中 | 收货、换装、拍摄 | 电子锁/封签、拍摄行程卡、客服 | 好评率、投诉率 |
| 离店 | 归还、退押金 | 一键归还、上门取件、酒店代收 | 归还准时率 |
| 行后 | 晒图、评价、复购 | 社区发帖、评价、优惠券、会员 | 复购率、UGC 量 |

### 3.3 B 端角色

| 角色 | 诉求 | 平台提供 |
| --- | --- | --- |
| 旅拍店/工作室 | 获客、档期填满、套餐销售 | 店铺页、作品集、档期、订单、结算 |
| 礼服馆/服装商家 | 库存周转、淡季收入 | 商品管理、一物一码库存、租期日历、清洗工单 |
| 独立摄影师 | 稳定订单、作品曝光 | 个人主页、套餐、接单、IM、结算 |
| 化妆师 | 接单、展示妆造 | 作品集、档期、上门/到店设置 |
| 酒店/民宿 | 提升住客体验、增加收入 | 酒店推荐位、配送合作、住客专属权益 |
| 平台运营 | 供给质量、履约、增长 | 审核、风控、客服、财务、数据后台 |

## 4. 竞品与差异化

| 类型 | 代表 | 优势 | 不足 | 我们的差异 |
| --- | --- | --- | --- | --- |
| 传统旅拍店 | 当地影楼/工作室 | 有本地供给和客片 | 信息不透明、价格不统一、线上弱 | 平台聚合 + 评价 + 担保 |
| 日常租衣平台 | 衣二三（已停运）、部分礼服租赁 | 有租赁流程经验 | 非目的地场景，不解决旅拍搭配 | 目的地场景 + 酒店配送 + 旅拍套餐 |
| 内容社区 | 小红书/抖音 | 种草强、流量大 | 交易和履约不闭环 | 内容直接挂同款/同摄影师，站内成交 |
| 电商 | 淘宝/拼多多 | 选择多、价格低 | 买断浪费、退换麻烦 | 租 instead of 买，含尺码/搭配/回收 |
| 本地生活 | 美团/大众点评 | 商家多、评价体系 | 租衣供给少、旅拍套餐不标准 | 垂直旅拍供应链 + 服饰租赁 |

**差异化壁垒（按时间顺序建立）**：

1. 目的地供给密度和履约数据（哪些商家准时、哪些衣服好租）；
2. 真实客片和“目的地—场景—穿搭”结构化内容；
3. 一物一码的库存/清洗/损赔数据；
4. 用户身材档案和偏好，提升尺码命中与推荐；
5. 酒店/民宿渠道和异地归还网络。

## 5. 商业模式

### 5.1 收入结构

| 收入项 | 说明 | 优先级 |
| --- | --- | --- |
| 租衣抽佣 | 按租金 15%–25% 抽佣，商家定价 | P0 |
| 摄影/化妆抽佣 | 按订单 10%–15% 抽佣 | P0 |
| 配送/取件费 | 同城专人、酒店配送、上门取件 | P1 |
| 押金/信用免押服务费 | 与支付/信用机构合作，收取少量服务费 | P1 |
| 租赁保险 | 损坏/丢失险，与持牌保司合作 | P1 |
| 会员 | 免押额度、折扣、优先档期、专属客服 | P2 |
| 广告/推广 | 商家置顶、目的地推荐位 | P2 |
| 增值 | 加急、精修、相册、路线策划 | P2 |
| 自营/自有品牌 | 爆款服饰、配饰、旅拍周边 | P3 |

### 5.2 定价与抽佣建议

- 租衣：按“3 天/5 天/7 天”阶梯定价，押金为售价的 50%–100%，支持信用免押；
- 摄影：套餐制（如 499 元基础跟拍 / 899 元含妆造 / 1,599 元半天跟拍+精修），定金 30%，尾款拍摄前或交付前；
- 化妆：到店 199–399 元，上门 399–699 元；
- 套餐：租衣 + 妆造 + 摄影打包，客单价 800–2,000 元；
- 平台抽佣：租衣 20%（可随品类调整），摄影/化妆 12%，配送费不进抽佣基数。

### 5.3 单位经济模型（假设，需实测）

**单租衣订单**

| 项目 | 金额（元） | 说明 |
| --- | --- | --- |
| 租金 GMV | 129 | 3 天，含 1 套主衣 + 1 件配饰 |
| 平台抽佣 20% | 25.8 | 平台收入 |
| 支付通道费 | 0.8 | 约 0.6% |
| 平台客服/运维分摊 | 3.0 | 按单分摊 |
| 平台贡献毛利 | 22.0 | 约 17% |
| 商家成本 | 清洗 15 + 包装 5 + 折旧 15 + 配送 25 | 商家承担，平台不补贴 |
| 商家毛利 | 约 43 | 商家有动力 |

**单摄影套餐**

| 项目 | 金额（元） | 说明 |
| --- | --- | --- |
| 套餐 GMV | 899 | 2 小时跟拍 + 9 张精修 |
| 平台抽佣 12% | 107.9 | 平台收入 |
| 平台成本 | 8 | 客服/纠纷/运维 |
| 平台贡献毛利 | 约 100 | 约 11% |

**组合客单（目标）**

- 租衣 129 + 摄影 899 + 化妆 299 = **1,327 元**；
- 平台收入约 **178 元**（租衣 25.8 + 摄影 107.9 + 化妆 44.9）；
- 平台履约/客服成本约 15 元，贡献毛利约 **163 元**；
- 若获客成本 80–120 元，组合订单可在首单打平或微赚。

> 关键结论：**租衣毛利薄，是入口和差异化；摄影/化妆/套餐/会员才是利润来源。** 因此产品必须把“租衣→摄影/化妆”的交叉销售做顺，而不是只卖衣服。

### 5.4 扩张路径

```text
阶段 1：轻资产平台（签约商家，抽佣）
   ↓ 单城 100–300 单/月，履约稳定
阶段 2：多城市复制 + 套餐化 + 会员
   ↓ 掌握爆款销量和供应链数据
阶段 3：自营爆款/自有品牌/区域仓 + 清洗中心
   ↓ 标准化程度提高
阶段 4：向酒店/旅行社/目的地平台输出供应链
```

## 6. 产品矩阵

| 端 | 用户 | 核心职责 | 上线阶段 |
| --- | --- | --- | --- |
| 微信小程序 | C 端游客 | 获客、浏览、下单、支付、订单、社区、客服 | MVP |
| App（iOS/Android） | 高频用户/会员/内容用户 | 社区、行程管家、推送、会员、AI 试穿 | 二期 |
| 商家工作台（小程序/H5） | 旅拍店/礼服馆 | 接单、库存、发货、归还、质检、结算 | MVP |
| 摄影师/化妆师端（小程序/H5） | 独立手艺人 | 作品、档期、接单、沟通、交付、结算 | MVP（轻量） |
| 运营后台（Web） | 平台团队 | 审核、订单、财务、风控、内容、数据 | MVP |

**为什么小程序优先**：

- 微信内分享链路短，客片/攻略可直接转发；
- 无需下载，适合“一年旅行 2–4 次”的低频用户；
- 微信支付、定位、手机号、订阅消息、客服能力齐全；
- 开发和获客成本低于 App，适合验证商业模式。

**App 的定位（二期）**：

- 不是把小程序的页面搬过去，而是做“留存型”产品：社区信息流、行程管家、会员权益、专属客服、拍摄提醒、AI 试穿/尺码推荐；
- 供给侧可单独做“商家版 App”，但前期用小程序/H5 足够。

## 8. 核心业务流程

### 8.1 租衣主流程

```text
① 选目的地/场景
      ↓
② 浏览衣服 → 看实拍/尺码/档期/押金
      ↓
③ 选款 → 选尺码 → 选配饰 → 选穿着日期
      ↓
④ 系统倒推：发货日 / 到达日 / 归还日（含物流缓冲）
      ↓
⑤ 填酒店/地址 → 选配送方式（酒店/自提/快递）
      ↓
⑥ 付租金 + 押金（或信用免押）+ 可选保险
      ↓
⑦ 商家接单 → 拣货 → 清洗/消毒 → 封签 → 发货
      ↓
⑧ 用户签收 → 穿着拍摄 → （可续租/换码）
      ↓
⑨ 离店归还：上门取件 / 酒店前台 / 快递寄回
      ↓
⑩ 商家签收 → 质检 → 押金退还 → 评价 → 完成
```

**订单状态机**

| 状态 | 触发 | 用户可操作 | 商家可操作 | 超时/异常 |
| --- | --- | --- | --- | --- |
| 待支付 | 提交订单 | 支付/取消 | — | 15 分钟未付自动取消 |
| 待确认 | 支付成功 | 联系客服/申请取消 | 确认库存/接单 | 2 小时未确认自动退款 |
| 待发货 | 商家确认 | 改地址（发货前） | 拣货/消毒/发货 | 超过发货时限赔付 |
| 已发货 | 填写物流 | 查看物流/联系 | 跟踪 | 物流异常预警 |
| 使用中 | 签收 | 续租/报损/预约归还 | — | 到期前 24h 提醒 |
| 待归还 | 到期前 1 天 | 预约取件/填写快递 | 提醒 | 逾期计费 |
| 归还中 | 用户寄出/上门取件 | 填单号 | 收货 | 物流丢件理赔 |
| 待质检 | 商家签收 | 等待 | 质检/拍照/定损 | 24h 内完成 |
| 待退押金 | 质检完成 | 确认/申诉 | 发起退款 | 1–3 个工作日到账 |
| 已完成 | 押金退还 | 评价/晒图 | 评价回复 | — |
| 售后/纠纷 | 用户申诉 | 举证/协商 | 举证 | 平台 48h 介入 |
| 已取消 | 取消/超时 | — | — | 按规则退款 |

> 关键：**租期不是“下单日到归还日”，而是“穿着日期 + 物流缓冲”**。系统要自动计算发货截止、到达预期、归还截止，避免用户和商家对“哪天该到”理解不一致。

### 8.2 摄影预约主流程

```text
① 选城市/风格（照片/视频/情侣/闺蜜/汉服/民族风）
      ↓
② 看摄影师/工作室作品集、套餐、评价
      ↓
③ 选套餐 → 选档期 → 填拍摄人数/酒店/需求
      ↓
④ 行前沟通（IM/电话）→ 确认服装、妆造、路线
      ↓
⑤ 付定金（30%）→ 平台派单/摄影师接单
      ↓
⑥ 拍摄 → 选片 → 精修 → 付尾款 → 交付
      ↓
⑦ 评价 → 结算（T+7）→ 客片授权/社区晒图
```

**订单状态机**

| 状态 | 说明 | 关键规则 |
| --- | --- | --- |
| 咨询中 | 未下单，IM 沟通 | 可发作品/套餐/档期 |
| 待付定金 | 已选档期，锁定 30 分钟 | 超时释放档期 |
| 待接单 | 已付定金，等待摄影师确认 | 2 小时未接单自动派单/退款 |
| 待服务 | 已接单，行前沟通 | 改期需提前 48h |
| 服务中 | 拍摄当天 | 迟到/爽约规则 |
| 待选片 | 拍摄完成 | 7 天内选片 |
| 修图中 | 已选片 | 精修 7–15 天 |
| 待付尾款 | 修图完成 | 付尾款后交付 |
| 已完成 | 交付完成 | 评价/结算 |
| 改期/取消 | 用户或商家发起 | 天气不可抗力免费改期 |
| 纠纷 | 质量/迟到/加价 | 平台仲裁 |

### 8.3 化妆预约流程

```text
选风格（日常/韩系/泰妆/民族/复古/新娘）
   ↓
看化妆师作品/套餐/档期
   ↓
选到店或上门 → 填地址/时间 → 付定金
   ↓
确认妆容需求（参考图/肤质/过敏）
   ↓
服务 → 评价 → 结算
```

化妆可以独立预约，也可以作为“租衣/摄影”的加购项。MVP 可先做“预约 + 定金 + 人工确认”，不急于做复杂排班。

### 8.4 归还、押金与赔付流程

```text
到期前 24h 提醒
   ↓
用户选择：上门取件 / 酒店前台代收 / 快递寄回
   ↓
商家签收 → 24h 内质检（拍照/视频留证）
   ↓
┌ 无损坏 → 全额退押金（T+1～T+3）
├ 轻微污渍 → 清洗费（明示标准）
├ 中度损坏 → 维修费/部分押金
├ 重度损坏/丢失 → 按残值赔付（上限=押金）
└ 用户有异议 → 平台仲裁（双方举证）
```

**规则建议**：

- 押金与租金分开收，押金不得用于经营周转；
- 支持微信支付分/芝麻信用免押，额度按信用分；
- 质检必须在 24h 内完成，超时默认无损坏；
- 扣款必须上传照片/视频和价目依据，用户确认后才扣；
- 争议 48h 内平台介入，超时平台先行赔付（可设上限）；
- 逾期：宽限 24h，之后按日租金 1.5 倍；超过 7 天协商买断；
- 丢失：按商品残值（售价 × 折旧系数）赔付，不超过押金。

### 8.5 商家履约流程

```text
接单 → 锁定实物件 → 检查成色 → 清洗/消毒 → 封签拍照
   → 打包（衣服/配饰/尺码贴/归还说明/快递单）
   → 发货 → 物流跟踪 → 用户签收
   → 归还签收 → 质检 → 清洗入库 → 释放库存
```

**商家履约指标**：

- 接单率、48h 发货率、准时送达率、归还质检时效；
- 差评率、赔付率、清洗合格率、库存准确率；
- 月度分级（S/A/B/C），C 级限流或淘汰。

### 8.6 平台侧流程

- 商家入驻审核（营业执照、法人、场地、样衣、客片）；
- 商品审核（实拍图、尺码表、押金、清洗说明）；
- 订单监控（超时、异常、纠纷）；
- 押金/退款/赔付审批；
- 分账结算（T+7，售后冻结）；
- 内容审核与推荐位管理；
- 城市运营（酒店合作、商家培训、活动）。

## 9. 关键产品规则

### 9.1 库存与档期

- **一物一码**：每一件实物有唯一编码，记录尺码、颜色、成色、清洗状态、当前订单；
- **按件锁档期**：用户选穿着日期后，系统锁定“发货日—归还日”整段，包含物流缓冲；
- **防超卖**：Redis 分布式锁 + 数据库事务 + 唯一约束/区间校验；
- **缓冲期**：同城发货 1 天、跨城 2 天；归还后预留 1 天质检；
- **调拨**：多城市之间可调拨，但需记录在途和清洗状态；
- **下架**：损坏/清洗中/丢失的实物件自动不可租。

### 9.2 尺码与合身

- 每个 SKU 提供：尺码表、模特身高/体重/三围、面料弹性、实拍视频；
- 用户填写身材档案（身高、体重、三围、鞋码），默认私密；
- 推荐尺码 + “偏大/偏小”提示；
- 同城支持免费换码一次（库存允许时）；
- 不合身可退货/换款，运费规则明示。

### 9.3 卫生与消毒

- 一客一洗一消毒，奢侈品/娇贵面料按面料标准；
- 每单生成清洗记录（时间、方式、操作人、照片）；
- 封签码：用户收到后检查封签是否完好；
- 详情页公示清洗流程和消毒标准；
- 抽检和用户举报机制，不合格商家下线。

### 9.4 配送与归还

- 配送方式：同城专人、顺丰/京东、酒店前台代收、门店自提；
- 酒店合作：前台签收/保管，离店代寄；
- 归还方式：上门取件、酒店代收、快递柜/驿站；
- 偏远地区/特殊酒店提前提示不可配送；
- 物流丢件：平台协调理赔，优先补发/退款。

### 9.5 押金与信用

- 押金比例：售价 50%–100%，按品类调整；
- 信用免押：微信支付分/芝麻信用，额度内免押；
- 押金存管：支付机构冻结/银行存管，平台不挪用；
- 退还时效：质检完成后 1–3 个工作日；
- 扣款争议：证据 + 用户确认 + 平台仲裁。

### 9.6 摄影服务规则

- 套餐明示：时长、服装套数、精修张数、底片是否全送、交通/门票谁承担；
- 定金 30%，尾款交付前；
- 改期：提前 48h 免费一次；48h 内按比例扣费；
- 天气：不可抗力免费改期；商家原因爽约双倍定金/平台赔付；
- 加片/加时/加妆造：线上下单补款，禁止私下加价；
- 成片：7 天内选片，精修 7–15 天，交付网盘/在线相册；
- 版权/肖像：用户授权平台展示需单独勾选，可随时撤回。

### 9.7 分账与结算

- 微信支付分账/支付宝分账；
- 租衣：用户确认收货/归还质检后 T+7 结算；
- 摄影：服务完成/交付后 T+7 结算；
- 售后/纠纷冻结对应金额；
- 平台服务费开票，商家租赁/服务费开票；
- 对账单可导出，支持按月结算。

### 9.8 评价与风控

- 只有真实订单可评价，租衣和摄影分开评；
- 评价维度：描述相符、卫生、尺码、履约、服务态度；
- 商家可回复，恶意差评可申诉；
- 风控：实名、手机号、设备指纹、收货地址异常、频繁退款、黑名单；
- 内容风控：盗图、虚假客片、导流、低俗、侵权。

## 10. 社区与内容

### 10.1 内容结构

- **目的地攻略**：城市/季节/天气/景点/机位/穿搭建议；
- **真实客片**：用户晒图、商家案例（标注“广告”）、摄影师作品；
- **穿搭公式**：如“海边白裙 + 草帽 + 藤编包”“古城马面裙 + 簪花”；
- **避坑指南**：尺码、隐形消费、天气、交通；
- **话题**：#三亚穿什么 #大理民族风 #闺蜜旅拍 #一衣多穿 #旅拍不踩坑。

### 10.2 同款挂载

帖子可挂：

- 同款衣服/配饰（跳转租衣详情）；
- 同款摄影师/套餐（跳转摄影详情）；
- 同款酒店/民宿（跳转合作页）；
- 同款妆容（跳转化妆师）。

平台按成交抽佣，创作者可获得 CPS 分成（二期）。

### 10.3 冷启动内容

- 签约 20–50 位本地 KOC/素人，提供免费租衣/折扣拍摄，换真实客片；
- 每个城市准备 100–200 篇种子内容，覆盖“穿什么/去哪拍/怎么约/多少钱”；
- 商家入驻时强制上传 10 套以上真实客片和 3 条视频；
- 运营每周做 1 个目的地话题，联合酒店/商家发券。

### 10.4 审核

- 机审（图片/文本/视频）+ 人审（客片真实性、盗图、广告标识）；
- 禁止站外导流、虚假种草、无授权肖像；
- 建立商家/创作者信用分，违规降权/封禁。

> 以上为量级估算，实际取决于城市、团队薪资、是否自营库存、是否做社区/App。建议先拿 3 个月小预算做“商家签约 + 手工履约”验证，再决定研发投入。

## 13. 关键指标

### 供给

- 签约商家数、在线可租实物件数、SKU 丰富度；
- 库存周转率、档期利用率、清洗周转天数；
- 商家接单率、48h 发货率、准时送达率、差评率、赔付率。

### 需求

- UV、搜索/筛选使用率、商详转化率、下单转化率；
- 客单价、租衣/摄影/化妆交叉购买率；
- 复购率、NPS、退货/退款率；
- 内容种草到下单的转化率。

### 财务

- GMV、take rate、贡献毛利；
- CAC、LTV、LTV/CAC；
- 押金坏账率、损耗率、物流成本占比；
- 单城盈亏平衡时间。

### 履约

- 准时送达率 ≥ 98%；
- 归还准时率 ≥ 95%；
- 质检 24h 完成率 ≥ 95%；
- 押金 3 个工作日内退还率 ≥ 98%；
- 纠纷率 ≤ 2%，48h 解决率 ≥ 90%。

## 14. 风险与合规

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 供给质量参差 | 口碑崩、退款/纠纷 | 商家分级、客片审核、神秘顾客、末位淘汰 |
| 尺码不合/货不对板 | 退款率高 | 详细尺码表、实拍视频、免费换码、押金兜底 |
| 卫生问题 | 用户信任危机 | 一客一洗一消毒、封签、清洗记录、抽检 |
| 库存超卖 | 履约失败 | 一物一码、档期锁、防超卖、超卖赔付 |
| 异地归还失败 | 押金纠纷 | 多点归还、酒店合作、上门取件、物流保险 |
| 损坏/丢失 | 赔付争议 | 明示规则、质检留证、保险、平台仲裁 |
| 押金资金池 | 合规风险 | 支付机构冻结/银行存管，不挪用，明确退还时限 |
| 个人信息（身材/地址/身份证） | 隐私合规 | 单独同意、加密、最小化、权限控制、可注销 |
| 旅游资质 | 若打包机酒/行程 | 与持牌旅行社合作，或只做租赁/预约 |
| 摄影版权/肖像权 | 侵权纠纷 | 授权书、客片使用单独勾选、可撤回 |
| 预付卡/会员 | 合规风险 | 避免大额储值，遵守单用途预付卡规定 |
| 内容审核 | 违规内容 | 机审+人审、举报、黑名单 |
| 季节性/天气 | 库存闲置/退改 | 多城市调度、预售、天气免费改期、保险 |

**重点合规清单**：

1. 平台/商家资质公示（营业执照、经营许可）；
2. 租赁押金规则、退改规则、损赔标准在下单前显著展示；
3. 个人信息保护：隐私政策、单独同意、数据出境评估（如适用）；
4. 电子商务法：平台责任、知识产权、消费者权益；
5. 发票：平台服务费与商家租赁/服务费分开开票；
6. 保险：与持牌保险机构合作，不无证经营保险业务；
7. 旅游：不无资质经营旅行社业务。

## 附录 A：术语

| 术语 | 含义 |
| --- | --- |
| SPU | 标准商品单元，如“法式白色长裙” |
| SKU | 规格单元，如“白色/S 码” |
| 实物件（Unit） | 一件可租赁的实物，一物一码 |
| 档期 | 某个实物件可租用的日期区间 |
| 物流缓冲 | 发货/归还路上预留的天数 |
| 押金存管 | 押金由支付机构/银行冻结，平台不挪用 |
| 信用免押 | 基于支付分/芝麻分免押金 |
| 分账 | 支付机构按比例把货款分给商家/平台 |
| Take rate | 平台从 GMV 中抽取的比例 |
| CAC / LTV | 获客成本 / 用户终身价值 |
