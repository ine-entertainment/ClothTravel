# 未命名项目 · 视觉方向与关键页面结构

- 版本：v0.1
- 日期：2026-11-04
- 关联：[产品策划案](01-产品策划案.md) · [功能清单](02-功能清单.md)

> 本文用于和设计师/开发对齐“长什么样、信息怎么排”，不是最终 UI 稿。建议先做 5 个关键页面的高保真：首页、商品详情、确认订单、订单详情、商家工作台。

---

## 1. 设计原则

| 原则 | 解释 | 落地 |
| --- | --- | --- |
| **信任优先** | 租衣是“把贴身衣服交给陌生人”，信任比好看更重要 | 实拍、尺码、清洗记录、押金规则、真实评价前置 |
| **内容感** | 用户是来“看出片效果”的，不是来逛仓库 | 大图/视频、客片、场景标签、搭配建议 |
| **女性友好** | 不制造身材焦虑，不影楼风，不低俗 | 真实身材模特、温和文案、隐私保护 |
| **低决策成本** | 选择多但不要乱 | 按目的地/场景/风格收敛，默认推荐 3 套 |
| **履约透明** | 用户最怕“不知道衣服到哪了、押金什么时候退” | 状态时间轴、物流、归还指引、押金进度 |
| **轻快** | 旅行是开心的事 | 圆角、留白、暖色点缀、微动效 |

## 2. 视觉方向

### 2.1 关键词

**奶油白、海盐蓝、珊瑚橘、杂志感、旅行手账、干净、松弛。**

避免：影楼金/大红、过度滤镜、复杂渐变、密集促销弹窗。

### 2.2 色彩

| 角色 | 色值建议 | 用途 |
| --- | --- | --- |
| 主色 | `#FF6B5A` 珊瑚橘 | 主按钮、价格、强调 |
| 辅色 | `#2F6F8F` 海盐蓝 | 信任、链接、标签 |
| 背景 | `#FFF9F2` 奶油白 | 页面底色 |
| 卡片 | `#FFFFFF` | 商品/订单卡片 |
| 文字主 | `#1F2328` | 标题/正文 |
| 文字次 | `#6B7280` | 说明/辅助 |
| 成功 | `#2E9E6B` | 已退还/已完成 |
| 警告 | `#D97706` | 待归还/逾期 |
| 错误 | `#DC2626` | 失败/赔付 |

### 2.3 字体与组件

- 字体：系统字体优先（PingFang SC / HarmonyOS Sans / Noto Sans SC）；
- 标题 20–24px，正文 14–16px，辅助 12–13px；
- 圆角：卡片 16px，按钮 999px（胶囊）或 12px；
- 图片比例：商品 3:4，客片 4:5/1:1，视频 9:16；
- 图标：线性 + 少量面性，避免过多装饰；
- 阴影：轻阴影，不用重投影；
- 动效：加购/支付成功/押金退还用小动效，不超过 300ms。

### 2.4 图片规范

- 商品：白底/场景各 1 组，至少 6 张；1 条 15 秒视频；
- 必须有：正面/背面/侧面/细节/配饰/尺码标；
- 模特信息：身高/体重/三围/所穿尺码；
- 客片：标注“真实客片/商家提供”，禁止盗图；
- 清洗/封签：可拍流程短视频，增强信任。

## 3. 小程序首页结构

```text
┌─────────────────────────────┐
│ 定位：三亚 ▾      [搜索] [消息] │
├─────────────────────────────┤
│ 今日天气 28°C 晴  · 适合海边   │
│ “来三亚穿什么？” → 查看穿搭攻略 │
├─────────────────────────────┤
│ [租衣] [找摄影] [找化妆] [城市] │  ← 四大入口
├─────────────────────────────┤
│ 精选客片（横滑 4:5 大图）        │
│  “白色长裙 + 草帽，海边出片”     │
│  可租同款 · 摄影师可约           │
├─────────────────────────────┤
│ 按风格选 → 海岛/法式/民族/汉服   │
├─────────────────────────────┤
│ 热门可租（双列卡片）             │
│  ¥129/3天  · 押金¥500 · 4.9分   │
├─────────────────────────────┤
│ 旅拍套餐（租衣+妆造+摄影）        │
│  ¥1,199 起 · 省 ¥300            │
├─────────────────────────────┤
│ 目的地灵感 / 酒店推荐 / 避坑指南  │
├─────────────────────────────┤
│ 底部 Tab：首页 订单 收藏 我的     │
└─────────────────────────────┘
```

**首页逻辑**：先给“目的地 + 天气 + 穿什么”的答案，再给商品；不要一上来就是商品瀑布流。

## 4. 租衣列表页

```text
┌─────────────────────────────┐
│ [三亚 ▾]  日期 3/12-3/15 ▾   │
│ 风格：全部 海岛 法式 民族 汉服  │
│ 筛选：尺码 价格 颜色 评分       │
├─────────────────────────────┤
│ ┌──────┐ 白色法式长裙          │
│ │ 3:4  │ ¥129/3天 · 押金¥500   │
│ │ 图片 │ S/M/L · 4.9分 · 可约  │
│ └──────┘ 含草帽+藤编包         │
├─────────────────────────────┤
│ ┌──────┐ 民族风刺绣套装        │
│ │ 图片 │ ¥159/3天 · 押金¥600   │
│ └──────┘ ...                  │
└─────────────────────────────┘
```

**要点**：

- 日期筛选置顶，用户先选“什么时候穿”；
- 卡片必须展示“租金/押金/尺码/评分/是否可约”；
- 支持“只看有我的尺码”；
- 无结果时给“换日期/换风格/预售登记”，不要空白。

## 5. 商品详情页

```text
┌─────────────────────────────┐
│ 图片/视频轮播（3:4）           │
│  1/8  · 视频  · 实拍           │
├─────────────────────────────┤
│ 白色法式长裙                   │
│ ¥129/3天  押金¥500  4.9分(86)  │
│ 含：裙子+草帽+藤编包            │
├─────────────────────────────┤
│ 选择：尺码 S M L  数量 1        │
│ 日期：3/12-3/15  [修改]         │
│ 配送：酒店/快递/自提            │
├─────────────────────────────┤
│ 尺码助手：身高体重 → 推荐 M     │
│ 模特 168/50kg 穿 S             │
├─────────────────────────────┤
│ 清洗消毒：一客一洗 · 封签 · 记录 │
│ 押金规则：归还质检后 1-3 天退    │
│ 损坏/逾期：查看规则             │
├─────────────────────────────┤
│ 真实客片（横滑）                │
│ 评价（按身材/场景筛选）          │
├─────────────────────────────┤
│ 底部：收藏  客服  ¥129  [立即租] │
└─────────────────────────────┘
```

**转化关键**：

- 首屏必须回答“多少钱、押金多少、有没有我的码、什么时候能到”；
- 尺码助手放在价格之后、评价之前；
- 清洗/押金规则不要藏在小字里；
- “立即租”前必须选日期，避免无效点击。

## 6. 确认订单页

```text
┌─────────────────────────────┐
│ 收货地址：三亚XX酒店 前台代收   │
│ 联系人/电话                    │
├─────────────────────────────┤
│ 租期：3/12 穿 - 3/15 还        │
│ 发货：3/10 前  到达：3/11       │
│ 归还：3/16 前  方式：上门取件   │
├─────────────────────────────┤
│ 商品：白色长裙 M ×1            │
│ 配件：草帽+包                 │
├─────────────────────────────┤
│ 租金 ¥129                     │
│ 押金 ¥500（信用免押/冻结）      │
│ 配送 ¥15                      │
│ 保险 ¥9（可选）                │
│ 优惠 -¥20                     │
│ 合计 ¥633                     │
├─────────────────────────────┤
│ ☑ 同意《租赁协议》《押金规则》  │
│ [提交订单]                    │
└─────────────────────────────┘
```

**要点**：

- 明确“穿几天、哪天到、哪天还”，不要只写“租期 3 天”；
- 押金单独一行，说明冻结/免押/退还时间；
- 配送方式影响费用和时效，默认推荐酒店代收；
- 协议必须勾选，但不要用默认勾选。

## 7. 订单详情与归还页

```text
┌─────────────────────────────┐
│ 状态：使用中                  │
│ 3/12 穿 · 3/16 前归还         │
│ [预约归还] [续租] [联系客服]   │
├─────────────────────────────┤
│ 物流：已签收 3/11 14:20        │
│ 商家：XX旅拍礼服馆             │
├─────────────────────────────┤
│ 押金：¥500 冻结中              │
│ 质检完成后 1-3 天原路退回       │
├─────────────────────────────┤
│ 归还方式：上门取件/酒店代收/快递 │
│ 归还地址/取件时间              │
│ 需归还：裙子+草帽+藤编包+封签袋  │
├─────────────────────────────┤
│ 订单信息/金额/协议             │
└─────────────────────────────┘
```

**要点**：

- 状态时间轴（已支付→已发货→已签收→使用中→待归还→已归还→质检→退押金）；
- 归还清单可勾选，避免配件遗漏；
- 押金进度可视化，减少客服咨询；
- 逾期前 24h 强提醒。

## 8. 摄影详情/预约页

```text
┌─────────────────────────────┐
│ 摄影师头像/名字/评分/接单数    │
│ 风格：海岛/情侣/闺蜜/汉服      │
├─────────────────────────────┤
│ 作品集（瀑布流/视频）          │
├─────────────────────────────┤
│ 套餐：2小时跟拍 ¥899           │
│ 含：9张精修+全部底片+1套服装   │
│ 不含：门票/交通/妆造           │
├─────────────────────────────┤
│ 档期：3/12 下午 可约           │
│ [选择档期]                    │
├─────────────────────────────┤
│ 行前沟通：文字/图片/语音        │
├─────────────────────────────┤
│ 底部：咨询  ¥899  [付定金预约]  │
└─────────────────────────────┘
```

**要点**：

- 作品集比文字更重要，首屏至少 3 张强相关客片；
- 套餐必须写清“含什么/不含什么/底片是否全送”；
- 档期直接可选，不要“先咨询再等回复”；
- 定金比例、改期规则前置。

## 9. 商家工作台

```text
┌─────────────────────────────┐
│ 今日：待接单 3 · 待发货 5 · 待质检 2 │
├─────────────────────────────┤
│ [订单] [库存] [商品] [结算] [评价] │
├─────────────────────────────┤
│ 待接单                        │
│ 订单 #20260312001  白色长裙 M  │
│ 租期 3/12-3/15  酒店配送       │
│ [接单] [拒单]                 │
├─────────────────────────────┤
│ 待发货                        │
│ [拣货] [消毒] [封签拍照] [发货] │
├─────────────────────────────┤
│ 待质检                        │
│ [签收] [拍照] [无损坏/定损]     │
└─────────────────────────────┘
```

**要点**：

- 商家端是“任务驱动”，不是后台表格；
- 首页只显示今天必须做的事；
- 发货/质检必须拍照留证；
- 结算透明，T+7 和冻结金额可见。

## 10. 运营后台

- 左侧导航：工作台、商家、商品、订单、退款/押金、结算、内容、客服、城市、营销、数据、系统；
- 工作台：今日订单、待审核、异常订单、待处理工单、GMV/退款/押金；
- 订单详情：用户/商家/商品/支付/物流/状态日志/操作记录一屏可查；
- 退款/押金：审批流 + 证据 + 操作日志；
- 数据：按城市/商家/品类/渠道拆。

## 11. 关键组件

| 组件 | 说明 |
| --- | --- |
| 档期日历 | 可选/锁定/不可用三态；选日期自动算发货/归还 |
| 尺码选择器 | 身高体重推荐 + 模特试穿 + 偏大偏小提示 |
| 押金说明卡 | 金额、冻结/免押、退还时间、扣款规则 |
| 状态时间轴 | 订单全链路节点，带时间戳 |
| 清洗信任卡 | 一客一洗、消毒方式、封签、记录 |
| 客片卡片 | 图片/视频、场景标签、同款挂载 |
| 套餐卡 | 含/不含、省多少钱、可约档期 |
| 归还清单 | 勾选配件、打包说明、取件方式 |
| 客服悬浮球 | 订单上下文带入，减少重复描述 |

---

## 12. 文案语气

- 用“你”，不用“亲”；
- 说人话，不堆术语：“归还后 1–3 天押金原路退回”，而不是“质检完成后退还”；
- 不制造焦虑：不用“再不租就没了”“最后 3 件”；
- 风险前置：“这件面料偏薄，建议内搭浅色内衣”；
- 出错时给方案：“抱歉，这件档期冲突，给你 3 个替代款”。

## 13. 设计交付顺序

1. 首页 + 商品详情 + 确认订单（决定转化）；
2. 订单详情 + 归还 + 押金（决定口碑）；
3. 摄影详情 + 预约（决定客单）；
4. 商家工作台（决定履约）；
5. 后台（决定运营效率）；
6. 社区/个人主页（二期）。

> 先做高保真可点击原型，找 5–10 位目标用户走一遍“选衣—下单—归还”，再进入开发。
