## 一页结论

### 做什么

面向女性旅行者的 **目的地服饰租赁 + 旅拍服务预约平台**：

1. **租衣**：按目的地、场景、天气选款，选尺码和租期，衣服送到酒店，离店时取回。
2. **找摄影**：看作品和风格，预约当地摄影师/工作室，行前沟通，拍摄，选片交付。
3. **找化妆**：预约妆造师，到店或上门，和租衣、摄影打包。
4. **城市攻略**：目的地景点、旅拍机位、酒店、天气、穿搭建议。
5. **社区**：真实客片、穿搭公式、出圈图，帖子可挂“同款衣服/同款摄影师”。

### 怎么落地

| 决策 | 建议 | 原因 |
| --- | --- | --- |
| 首发端 | **微信小程序** | 获客和分享成本低，微信支付闭环，先验证交易 |
| App | **二期再做** | 社区和复购起来后，App 才有留存价值 |
| 经营模式 | **平台轻资产**：签当地商家，平台抽佣 | 不自建库存，先跑通履约 |
| 首发范围 | **1 个城市 + 1 个核心场景** | 租衣是重履约，跨城复制前先跑通单城模型 |
| MVP 功能 | 租衣 + 摄影预约 + 订单/押金/物流 + 商家后台 | 先把“选衣—送达—归还—退押金”闭环做实 |
| 二期功能 | 化妆、社区、会员、App、多城市 | 社区需要内容和用户密度，过早做会空 |
| 三期 | 自营爆款、自有品牌、供应链、AI 试穿 | 有销量和数据后再向上游走 |

### 成败关键

不是“把页面做出来”，而是这 5 件事：

1. **供给质量**：旅拍店/礼服馆服务参差，必须做商家分级、客片审核、履约考核和淘汰。
2. **尺码与库存**：租赁是一物一码，必须按“实物件”管理档期，不能按 SKU 粗放超卖。
3. **卫生信任**：一客一洗一消毒、封签、清洗记录可视化，这是女生租衣的底线。
4. **异地归还**：酒店代收、上门取件、快递柜多点覆盖，归还体验决定复购。
5. **押金与损赔**：押金存管/信用免押、损坏分级赔付、争议仲裁，避免“押金不退”口碑崩塌。

### 核心闭环

```text
刷到目的地内容/客片
      ↓
选城市 → 看穿搭攻略 → 选衣服（风格/尺码/租期）
      ↓
填写酒店/地址 → 付租金+押金 → 商家消毒打包
      ↓
送到酒店 → 穿着拍摄 → 预约摄影师/化妆师
      ↓
离店归还（上门/酒店代收/快递）→ 质检 → 退押金
      ↓
社区晒图/评价 → 同款转化 → 复购或推荐闺蜜
```

### 建议首发城市（待定）

按“旅拍热度 + 商家供给 + 酒店密度 + 场景辨识度”综合评估：

- **三亚**：海岛/婚纱/度假，客单价高，四季可做，但供给竞争激烈。
- **大理 / 丽江**：古城、民族风、苍山洱海，内容传播强，适合汉服/民族服饰。
- **厦门**：文艺、海岛、街拍，年轻女性客群匹配。
- **重庆**：城市夜景、赛博朋克、辣妹风，适合citywalk。
- **西安**：汉服/唐装/古城墙，服饰租赁需求天然存在。
- **长沙**：街拍、夜生活、年轻客群，适合短途周末游。

> 建议先选 **1 个城市做深**（例如三亚或大理），签约 15–30 家商家、300–500 个可租实物件，跑通 100 单真实履约，再复制。

## 现在需要你确认的 6 件事

1. **首发城市和场景**：三亚海岛、大理古城、西安汉服，还是你所在的城市？
2. **模式**：纯平台抽佣，还是平台先自采一小批爆款做自营试点？
3. **预算与团队**：自研还是外包？首期可投入多少？希望几个月上线？
4. **供给资源**：你手上是否已有旅拍店、礼服馆、摄影师、酒店资源？
5. **品牌调性**：项目暂用「未命名项目」，后续是否再单独定品牌名？偏“高端旅拍”还是“年轻性价比”？
6. **首期边界**：是否接受“先不做社区和 App”，把预算集中在租衣履约和摄影预约？

确认后，下一步可以产出：**页面原型（小程序 + 商家端）→ 数据库设计 → 开发排期与报价**。
